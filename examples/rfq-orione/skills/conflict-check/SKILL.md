# Check for conflicts before a contract

A new contract can be a good deal and still cost the company its best customer.
What makes it a conflict is rarely in the request: it is in the company's memory —
who our historical customers are, who their partners are, what we promised them.
That memory lives here, on this machine, and nowhere else.

## Method

1. Read the request: which company, what work, which deadline.
2. List **every** file in the historical memory folder you were given, then read
   each one. Do not stop at the first file.
3. Look for the new company's name in the memory. For each hit, note:
   - which existing customer it is connected to, and how (partner, supplier,
     competitor, joint venture);
   - what we promised that customer (NDA clauses, requests made in meetings);
   - how much that customer is worth to us, if the memory says.
4. Decide:
   - **No conflict found** → say so, name the files you checked, and write the
     draft contract as asked.
   - **Conflict found** → do NOT write the draft. Write instead a short note for
     the CEO, in this order:
     1. the conflict in one sentence;
     2. the evidence, one line per document, with the file name;
     3. what we are bound to do (e.g. the notice an NDA requires);
     4. the options, with what each one risks;
     5. the sentence: «Serve una decisione del CEO prima di procedere.»

## Rules

- Never quote the historical memory outside this note, and never suggest sending
  it to the new company.
- Never decide on the CEO's behalf: present the options, do not pick one.
- Answer in the language of the request.
